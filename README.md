## 🔑 GitHub-токен (опционально)

Приложение время от времени обращается к GitHub API, чтобы проверять
обновления. По умолчанию GitHub разрешает **60 запросов в час** на IP.
Если этого не хватает (например, ты часто перезапускаешь приложение),
можно задать персональный токен — лимит поднимется до **5000 запросов в час**.

Токен **не хранится** в `config.json` и **не показывается** в приложении.
Он лежит только в переменных окружения Windows.

### Как настроить

**Шаг 1. Создай токен на GitHub**
1. Открой https://github.com/settings/tokens
2. `Generate new token` → `Generate new token (classic)`
3. Название: `ZapretManager`
4. Expiration: `No expiration` (или на твой вкус)
5. Scopes: поставь галочку у **`public_repo`**
6. `Generate token`, скопируй строку `ghp_...`
   (показывается один раз — не потеряй!)

**Шаг 2. Добавь переменную окружения**
1. `Win` → начни печатать «Изменение переменных среды» → открой
   **«Изменение переменных среды текущего пользователя»**.
2. В блоке «Переменные среды пользователя» нажми **Создать**.
3. **Имя переменной:** `GITHUB_TOKEN`
4. **Значение:** вставь токен `ghp_...`
5. Сохрани все окна.

**Шаг 3. Перезапусти приложение**
Полностью закрой Zapret Manager и запусти заново.
В настройках (вкладка `🔑 GitHub токен`) статус должен стать:
**«Настроен ✓ (лимит 5000 запросов/час)»**.

### Как проверить

Открой в браузере https://api.github.com/rate_limit
В блоке `"core"` увидишь `"limit": 5000` (вместо 60).

### Если токен утёк

Немедленно отзови его по ссылке https://github.com/settings/tokens
и создай новый.

### Если не хочешь возиться

Ничего страшного — оставь как есть. Приложение будет работать
с лимитом 60 запросов/час. Этого хватает для обычного использования.
Токен нужен, только если ты часто перезапускаешь приложение или
разрабатываешь его.
