# Zapret Manager

Графическая обёртка для `zapret-discord-youtube` и `tg-ws-proxy` под Windows.

Приложение показывает состояние службы zapret, позволяет быстро запустить,
остановить или перезапустить выбранную стратегию, открыть `service.bat` для
тонкой настройки и обновить компоненты в один клик.

## Что нового в 0.3.0

- Новое боковое меню: Zapret, Telegram Proxy, Обновления, Настройки.
- Вкладка Zapret помещается без прокрутки.
- Остался один рабочий конфиг `general (ALT11).bat` со всеми нужными доменами
  и списками; остальные стратегии убраны в `zapret/backup_strategies`.
- Первый запуск полностью автоматический: компоненты скачиваются без вопросов.
- Исправлено определение статуса: внешние запущенные zapret/tgproxy теперь
  отображаются как «Запущен», а не «Не установлен».
- Убраны разделы «Исключения» и «Фирменные конфиги». Исключения обновления
  обрабатываются внутри приложения.
- Обновление обёртки перенесено на вкладку «Обновления».
- Удаление приложения очищает службу zapret, процессы, автозапуск,
  `%LOCALAPPDATA%\ZapretManager` и папку установки.
- Обновлён `general (ALT11).bat`: исправлены звонки Discord на портах
  `2053/2083/2087/2096/8443` (`seqovl=664`, `sferum`/`stun2`).
- `ipset-all.txt` остаётся пустым (`203.0.113.113/32`), чтобы IPSet не ломал Steam.

## Возможности

- Статус службы, версия zapret и активная стратегия.
- Быстрый запуск, остановка и перезапуск выбранной стратегии.
- Запуск `service.bat` без очистки экрана.
- Проверка и обновление `zapret-discord-youtube`, `tg-ws-proxy` и самой обёртки.
- Автоматическая подготовка при первом запуске.
- Настройки: автозапуск и рабочие папки.
- Отдельная вкладка для `tg-ws-proxy`.

## Требования

- Windows 10/11 x64.
- Права администратора для управления службой zapret.
- Для сборки: Python 3.12, PyInstaller, Inno Setup 6.

## Запуск из исходников

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```

При старте приложение попросит UAC и перезапустится с правами администратора.

## Сборка

```powershell
python -m PyInstaller build.spec
```

Установщик:

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\setup.iss
```

Готовый установщик появится в `dist/ZapretManager-Setup-<version>.exe`.

## Релиз

Версия хранится в `app/version.py` и должна совпадать с тегом:

```powershell
git tag v0.3.0
git push origin main --tags
```

GitHub Actions соберёт `.exe`, установщик и создаст релиз.

## Структура

```text
app/
  main.py                 точка входа и UAC
  version.py              версия приложения
  assets/                 иконка, списки, рабочий конфиг
  core/                   работа с zapret, tgproxy, обновлениями, конфигом
  gui/                    главное окно и мастер первого запуска
installer/setup.iss       Inno Setup
build.spec                PyInstaller
```

## GitHub-токен (опционально)

Без токена GitHub API даёт 60 запросов в час. Если этого мало, создай
токен на https://github.com/settings/tokens и добавь переменную окружения
`GITHUB_TOKEN`. Токен не хранится в `config.json`.
